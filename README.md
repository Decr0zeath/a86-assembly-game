# Crossword Puzzle and Car Game Using Assembly

This was a final project for during my undergrad years for a course called `Computer System Organizationwith Assembly Language` (2018).

This is basically a `Crossword Puzzle` and a `Car Game` combined in one assembly file.

This is coded using `a86-asm` and ran in an emulator using `MS-DOSBox` 

This was a very fun project. 

I remember sleeping only 3 hours a day, eating pancit canton with green cobra every 1am for straight 2 weeks just to finish this project haha.

Not because it was hard but because I seriously enjoyed making this, I forego playing DotA 2 for the that two week time-frame just to create this masterpiece.
